# OuderHulp AI\n\nOuderhulp-app met echte AI-analyse en advies.\n\n## Instellen\nVoeg op de hostingomgeving `OPENAI_API_KEY` toe. Optioneel: `OPENAI_MODEL=gpt-5.6-luna`. Zet de sleutel nooit in `index.html`.\n\nDeze repo is ingericht voor Vercel serverless hosting. GitHub Pages kan de API-functie niet uitvoeren.\n\nVoor productie: voeg privacybeleid, bewaarbeleid, rate limiting en verdere beveiliging toe.
